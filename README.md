## 阿克曼转向分析

```
轴距 L=150mm，弯道半径 R=400mm
内侧前轮转角 ≈ arctan(L/(R-轮距/2)) ≈ arctan(150/332) ≈ 24.3°
外侧前轮转角 ≈ arctan(L/(R+轮距/2)) ≈ arctan(150/468) ≈ 17.8°
```

舵机 60°-120° 范围（±30°）通过连杆映射到前轮转角。实际转角由连杆臂长决定，需实测校准。

## 循迹算法：连续P控制

### 1. 每路传感器独立计算黑度
```
黑度[i] = 白底基准[i] - 当前读数[i]
```
白底≈950 → 黑度≈0；黑线≈300 → 黑度≈650。5路各自独立，适应R1等传感器个体差异。

### 2. 死区滤波
黑度 < DEADBAND(100) 的传感器视为白底噪声，忽略不参与计算。

### 3. 加权位置误差（连续值 -2.0 ~ +2.0）
```
位置权重: L2=-2, L1=-1, M=0, R1=+1, R2=+2
误差 = Σ(位置 × 黑度) / Σ(黑度)
```

### 4. P控制 → 连续舵机角度
```
舵机角度 = 90° + KP_GAIN × 误差
KP_GAIN=30 → 最大偏转 ±60°
```

### 5. 差速辅助 + 动态降速
```
左转: 左轮=base×0.65, 右轮=base×1.35
右转: 左轮=base×1.35, 右轮=base×0.65
|误差|>1.0 → 整体×0.60
|误差|>0.3 → 整体×0.80
```
