# 工程实践循迹小车 — 电控部分

## 赛道信息

| 参数 | 值 | 说明 |
|------|-----|------|
| 赛道类型 | 白底黑线 | 黑线宽度 ≈ 拇指宽 |
| 赛道宽度 | 45 cm | 白色区域总宽 |
| 小车宽度 | 20 cm | 阿克曼转向 + 差速后驱 |
| 弯道类型 | 直角弯（90°） | 类似 Minecraft 铁轨布局 |
| 场地布局 | 2×4 地块 | 直线 + 直角弯组合 |
| 运行方向 | →↑→↑→↑→↑ | 前→左→左→前→右→右→前→右→右→前 |

## 硬件接线表

| 引脚 | 连接设备 | 说明 |
|------|----------|------|
| D2 | 舵机 S3003 | 前轮转向，180°模拟舵机，90°为直行 |
| **A+** / **A-** | RL 后左电机 (GM37-520) | 直流电机，A通道输出 |
| **B+** / **B-** | RR 后右电机 (GM37-520) | 直流电机，B通道输出 |
| A0 (AIN0) | 循迹传感器 L2 | 最左侧 |
| A1 (AIN1) | 循迹传感器 L1 | 左侧 |
| A2 (AIN2) | 循迹传感器 M  | 正中间 |
| A3 (AIN3) | 循迹传感器 R1 | 右侧 |
| A4 (AIN4) | 循迹传感器 R2 | 最右侧 |

## 电机驱动板控制引脚（需根据实际驱动板确认）

| 功能 | 引脚 | 说明 |
|------|------|------|
| M1 方向 | D12 | 电机A（左轮）方向，HIGH=正转 |
| M1 速度 | D3 | 电机A PWM调速 |
| M2 方向 | D13 | 电机B（右轮）方向，HIGH=正转 |
| M2 速度 | D11 | 电机B PWM调速 |

> **注意：** 以上电机控制引脚基于常见 L298P 驱动板默认引脚。如实际板子不同，请修改 `src/config.h`。

## 小车基本参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 驱动方式 | 阿克曼转向 | 前轮舵机转向 + 后轮双电机差速 |
| 舵机型号 | S3003 | 180° 模拟舵机 |
| 电机型号 | GM37-520 | 直流减速电机 ×2 |
| 传感器 | 5路模拟循迹 | 白底黑线 |
| 主控 | Robot Mboard KR-duino V1.5 | ≈ Arduino Uno R3 |
| 控制策略 | 纯 P 控制 | 后续升级为 PID |
